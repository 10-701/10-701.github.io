k-means seeding, Lloyd, and swap local search

Generate 2-D Gaussian clusters, seed centers at random or with k-means++, run Lloyd's algorithm, then improve the result with LocalSearch++ swaps (Lattanzi & Sohler, 2019).

Pruning an oversampled seeding is the same k-means problem, one level up: each current center becomes a data point, weighted by how many points it serves. Panels 2–4 then cluster those points down to k (K by default). This is the second stage of k-means|| and of Guha et al.'s streaming reduction; the guarantee needs the weights. While this mode is on, the vs-ground-truth tile and the purple chart line score the new centers on the original data.

Things to try

  1. Random seeding with unequal variances. Small, tight clusters often get no center, and Lloyd can't move a center across a gap.
  2. D² vs uniform candidates. Run 50 swaps of each from the same Lloyd optimum. Uniform proposals mostly land in big clusters that are already covered.
  3. Oversample (k > K). Cost drops below the ground-truth line: extra centers always lower the objective. Pruning back to K is the reclustering step.
  4. Random removal. Many more swaps are rejected, because the deleted center was usually doing useful work.
  5. Oversample, then recluster. Seed k = 2K with k-means++, run Lloyd, recluster to K, then end the mode and polish. Compare with plain k-means++ at k = K, and try unchecking the weights.

Ground truth = cost of the generating partition with its sample means, using K centers. It is an upper bound on the optimal K-center cost.
